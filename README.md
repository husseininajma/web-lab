# [web-lab]

## Description

This project is a navigation bar with nav items and a light-mode toggle button.
Clicking the button changes the appearance of the navigation elements.

## Features

- Navigation bar
- Hover effects
- light-mode toggle
- Responsive layout

## Technologies Used

- HTML
- CSS
- JavaScript
